# 数安硬件数据中台 前端对接 API 文档

版本：1.1  
日期：2026-08-24  
服务类型：纯后端 API，前后端分离

本文档覆盖前端对接本服务的全部接口：第三方视频平台（第 2-6 章）、气象与过车数据查询（第 7 章）、海康视频（第 8 章）。

## 1. 基本约定

### 1.1 服务地址

联调地址：

```text
https://kab-equip.sazn-ai.com:8070
```

第三方视频平台接口统一前缀（仅第 2-6 章的接口使用）：

```text
/api/video-platform
```

### 1.2 Access Token

本章业务接口都必须携带后台生成并人工分配的 Opaque Access Token（唯一的例外是实况/回放返回的 HLS 播放地址，其自带短期签名，见「开始实况」）：

```http
Authorization: Bearer hx_live_<public_id>.<secret>
```

示例：

```bash
curl "https://kab-equip.sazn-ai.com:8070/api/video-platform/cameras?page=1&page_limit=10" \
  -H "Authorization: Bearer hx_live_demo.xxxxxxxxx"
```


> 此节仅随文档线下分发给对接人，**不提交到 git**；发送后请从本地文件删除或还原（见下方约束：Token 不得入库）。

约束：

- Token 由后端 CLI 生成，前端不能自行创建。
- Token 不得写入 URL、源码、构建变量或日志。
- 浏览器联调工具只允许保存在当前标签页的 `sessionStorage`。
- 收到 HTTP 401 后应删除缓存 Token，并提示重新获取或输入。

### 1.3 时间格式

录像相关时间使用服务器本地时区的字符串：

```text
YYYY-MM-DD HH:mm:ss
```

示例：`2026-08-24 09:30:00`。

开始时间必须早于结束时间，否则返回 HTTP 422。

### 1.4 成功响应

本服务有两套响应信封，按接口分组使用：

**第 2-6 章（第三方视频平台）**沿用视频平台控制台信封：

```json
{
  "code": 200,
  "message": "成功",
  "data": {},
  "count": 0
}
```

- `data` 类型由具体接口决定。
- `count` 只在分页或上游返回数量时出现。
- HTTP 2xx 且 `code = 200` 表示成功。

**第 7-8 章（数据查询、海康视频）**使用本站统一信封：

```json
{
  "code": 200,
  "message": "ok",
  "path": "/api/weather/list",
  "success": true,
  "data": {}
}
```

分页接口的 `data` 形如 `{"records": [], "total": 0, "size": 10, "current": 1, "pages": 0}`。

### 1.5 认证错误

Token 缺失、格式错误、无效、过期或已撤销统一返回：

```http
HTTP/1.1 401 Unauthorized
WWW-Authenticate: Bearer
Content-Type: application/json
```

```json
{
  "code": 401,
  "message": "Access Token 无效或已过期",
  "path": "/api/video-platform/cameras",
  "success": false
}
```

认证存储暂时不可用时返回 HTTP 503，前端应提示“认证服务暂时不可用”，不要当成 Token 错误清除凭证。

### 1.6 上游错误

第三方视频平台超时、不可用或业务失败统一映射为 HTTP 502：

```json
{
  "error": {
    "code": "UPSTREAM_TIMEOUT",
    "message": "视频平台请求超时"
  }
}
```

可能的 `error.code`：

| 错误码                      | 含义                           |
| --------------------------- | ------------------------------ |
| `UPSTREAM_TIMEOUT`          | 第三方平台请求超时             |
| `UPSTREAM_UNAVAILABLE`      | 网络错误或第三方平台不可用     |
| `UPSTREAM_INVALID_RESPONSE` | 第三方返回非 JSON 或结构不完整 |
| `UPSTREAM_BUSINESS_ERROR`   | 第三方返回非 200 业务码        |

`UPSTREAM_BUSINESS_ERROR` 可能附带 `upstream_code`。前端不得向终端用户展示内部地址、Token 或响应堆栈。

### 1.7 参数校验错误

请求字段缺失、类型不符或时间范围错误返回 HTTP 422，响应为 FastAPI 标准校验结构：

```json
{
  "detail": [
    {
      "type": "value_error",
      "loc": ["body", "start_time"],
      "msg": "Value error, 开始时间必须早于结束时间",
      "input": "2026-08-24 10:00:00"
    }
  ]
}
```

## 2. 相机列表

```http
GET /api/video-platform/cameras?page=1&page_limit=10
Authorization: Bearer <token>
```

查询参数：

| 参数         | 类型    | 必填 | 默认值 | 限制     |
| ------------ | ------- | ---- | ------ | -------- |
| `page`       | integer | 否   | 1      | `>= 1`   |
| `page_limit` | integer | 否   | 10     | `1..100` |

成功响应：

```json
{
  "code": 200,
  "message": "成功",
  "data": [
    {
      "id": 1,
      "equipment_no": "E-001",
      "camera_serial": "S-001",
      "camera_code": "C-001",
      "camera_name": "入口球机",
      "status": "online",
      "ptztype": 1
    }
  ],
  "count": 1
}
```

字段说明：

- 上游 `equipment_No` 已统一转换为 `equipment_no`。
- `status` 以第三方实时推送为准（无推送时为上游快照）。
- `ptztype === 3` 表示不支持云台，前端应禁用云台控制。

## 3. 开始实况

```http
POST /api/video-platform/live/start
Authorization: Bearer <token>
Content-Type: application/json
```

请求体：

```json
{
  "equipment_no": "E-001",
  "camera_serial": "S-001",
  "camera_code": "C-001"
}
```

成功响应：

```json
{
  "code": 200,
  "message": "成功",
  "data": {
    "streamUrl": "/api/video-platform/stream/AbCdEf/index.m3u8?expires=1787542200&signature=8f19...",
    "rawStreamUrl": "https://upstream.example/live/index.m3u8"
  }
}
```

- 播放器必须使用 `streamUrl`。
- `streamUrl` 已包含短期签名，HLS 请求不添加 Bearer Token。
- `rawStreamUrl` 仅用于获授权技术人员诊断，可能不存在；不得持久化或对外展示。

## 4. 停止实况

```http
POST /api/video-platform/live/stop
Authorization: Bearer <token>
Content-Type: application/json
```

请求体为相机三要素（`equipment_no` / `camera_serial` / `camera_code`，均必填）。成功时 `data` 通常为上游返回的空数组或空对象：

```json
{
  "code": 200,
  "message": "成功",
  "data": []
}
```

前端停止播放时应同时销毁播放器实例，并尽力调用本接口。即使停止上游失败，也必须清理本地播放器状态。

## 7. 气象与过车数据查询

> 本组接口使用本站统一信封（见 1.4）——分页数据在 `data.records`，无顶层 `count` 字段。

四个查询接口均为 `GET`、需 Bearer Token、按 id 倒序、参数全部可选：

### 7.1 气象数据

```http
GET /api/weather/list?clientId=&startTime=&endTime=&pageNo=1&pageSize=10
Authorization: Bearer <token>
```

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `clientId` | string | 否 | 设备 ID 精确筛选 |
| `startTime` / `endTime` | string | 否 | 检测时间范围（`YYYY-MM-DD HH:mm:ss`） |
| `pageNo` | integer | 否 | 页码，默认 1 |
| `pageSize` | integer | 否 | 每页条数 1-100，默认 10 |

`data.records` 元素 = 基础字段 + 气象站动态字段展平（不同气象站推送字段不同）：

```json
{
  "id": 1,
  "clientId": "weather-station-01",
  "detectedTime": "2026-08-24T09:00:00",
  "createTime": "2026-08-24T09:00:05",
  "temperature": 26.5,
  "humidity": 62
}
```

（`temperature` / `humidity` 等为该气象站实际推送的字段，以后端返回为准。）

## 8. 海康视频接口（两台海康设备）

> **前置**：海康视频播放依赖 WEB 插件 exe（仅支持 Chrome / Edge），需在终端预先安装；本站静态联调页 `/static/hikiot_player.html` 即按本章接口实现，可作为参考。

### 8.1 设备列表

```http
GET /api/hikiot/devices?page=1&size=20
Authorization: Bearer <token>
```

本站统一分页信封，`data.records` 元素含 `deviceSerial`、`name`、`status`（1=在线、2=离线）。

### 8.2 通道列表

```http
GET /api/hikiot/channels?deviceSerial=<序列号>
Authorization: Bearer <token>
```

查询参数：

| 参数           | 类型   | 必填   | 说明                                    |
| -------------- | ------ | ------ | --------------------------------------- |
| `deviceSerial` | string | **是** | 设备序列号（8.1 返回的 `deviceSerial`） |

`data` 为数组，元素含 `channelNo`、`status`。

### 8.3 播放初始化（聚合数据）

```http
GET /api/hikiot/play/init?deviceSerial=<序列号>&channelNo=1
Authorization: Bearer <token>
```

查询参数：

| 参数           | 类型    | 必填   | 默认值 | 说明       |
| -------------- | ------- | ------ | ------ | ---------- |
| `deviceSerial` | string  | **是** | -      | 设备序列号 |
| `channelNo`    | integer | 否     | 1      | 通道号     |

一次返回 WEB 插件初始化所需的全部数据，`data` 含：

| 字段 | 用途 |
| --- | --- |
| `bSecret` / `openAppkey` / `openAppSecret` | 插件 `setSecretConfigInfo` 配置 |
| `appAccessToken` / `userAccessToken` | 插件 `initWndParam` 凭证 |
| `windowMode` | 固定 1（Chrome >= 139 白屏修复） |
| `ezAccessData` / `resourcesData` / `tokensData` / `capacitysData` | 插件初始化整包数据（JSON 字符串，直接透传） |

不做缓存：取流凭证有有效期，每次实时拉取。

### 8.4 视频抓拍

```http
POST /api/hikiot/capture
Authorization: Bearer <token>
Content-Type: application/json

{"deviceSerial": "E-001", "channelNo": 1}
```

请求体参数：

| 参数           | 类型    | 必填   | 默认值 | 说明                       |
| -------------- | ------- | ------ | ------ | -------------------------- |
| `deviceSerial` | string  | **是** | -      | 设备序列号（缺失返回 400） |
| `channelNo`    | integer | 否     | 1      | 通道号                     |

`data.captureUrl` 为抓拍图片地址。

### 8.5 预置点

```http

Authorization: Bearer <token>
```

查询参数：

| 参数           | 类型    | 必填   | 默认值 | 说明       |
| -------------- | ------- | ------ | ------ | ---------- |
| `deviceSerial` | string  | **是** | -      | 设备序列号 |
| `channelNo`    | integer | 否     | 1      | 通道号     |

```http
POST /api/hikiot/ptz/preset/go
Authorization: Bearer <token>
Content-Type: application/json

{"deviceSerial": "E-001", "channelNo": 1, "presetId": 1}
```

请求体参数：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `deviceSerial` | string | **是** | - | 设备序列号（缺失返回 400） |
| `channelNo` | integer | 否 | 1 | 通道号 |
| `presetId` | integer | **是** | - | 预置点 ID（8.5 列表返回；缺失返回 400） |

## 9. 前端请求封装参考

```ts
type Envelope<T> = {
  code: number;
  message: string;
  data: T;
  count?: number;
};

type ErrorEnvelope = {
  code?: number;
  message?: string;
  error?: {
    code?: string;
    message?: string;
    upstream_code?: string | number;
  };
};

export async function request<T>(
  path: string,
  accessToken: string,
  init: RequestInit = {},
): Promise<T> {
  const response = await fetch(path, {
    ...init,
    headers: {
      'Content-Type': 'application/json',
      Authorization: `Bearer ${accessToken}`,
      ...init.headers,
    },
  });

  const payload = (await response.json()) as Envelope<T> & ErrorEnvelope;

  if (!response.ok) {
    const message =
      payload.error?.message ??
      payload.message ??
      `请求失败（HTTP ${response.status}）`;
    throw Object.assign(new Error(message), { status: response.status });
  }

  return payload.data;
}
```

HLS 播放器不得复用这个请求封装；直接把 `data.streamUrl` 交给 hls.js、mpegts.js 或兼容播放器。

## 10. 受认证影响的现有接口

认证机制启用后，以下现有接口也必须携带 Bearer Token（前两组的详细说明见第 7、8 章）：

- `/api/weather/list`、`/api/vehicle/pass/list`、`/api/vehicle/overspeed/list`、`/api/alert/list`（见第 7 章）
- `/api/hikiot/*` 气象与过车数据、海康视频接口（见第 8 章）

以下现有接口仍不要求 Bearer Token：

- `/api/hardware/*`
- `/`
- `/health`
- `/doc.html`
- `/v3/api-docs`
- `/static/*`

现有前端和海康联调页需要在认证上线前同步增加 `Authorization: Bearer <token>`。

## 11. 联调顺序

1. 向后端管理员申请独立 Access Token。
2. 调用相机列表，确认 Token 和上游配置有效。
3. 选择在线相机并开始实况，使用返回的签名 `streamUrl` 播放。
4. 测试停止实况、录像查询和回放。
5. 调用气象 / 过车 / 预警查询接口，确认数据展示与分页（见第 7 章）。
6. 调用海康设备列表与播放初始化，确认两台海康设备视频可播（见第 8 章，需安装 WEB 插件）。
7. 使用错误、过期和已撤销 Token 验证 401 处理。
8. 使用过期或篡改的 HLS URL 验证重新取流逻辑（403/404/410 时重新调用开始实况/回放）。
